# 图导入

## graphspace/DEFAULT/schema

图导入这里, 不友好的地方也比较多

- Schema 这里需要加几个**默认模板**,  相当于 hubble 内置方便参考
- 点击 "创建 Schema 模板" 的框 "创建" 框整体可以大一点, 特别是 Schema 的框可以更大默认
    - 然后 Schema 模板名称 改为 "模板名称"
    - "Schema" 改为 "Schema 内容", 然后必须给模板和链接导向官网参考
    - schema 创建这里每个参数都需要问号指引
    - 灰色提示也应该填写有效说明
    - Schema 内容下面可以给几个当前已有模板 list, 点击可以加在到框里方便参考修改

## /source 页面

- 同样非常不友好, 缺乏默认数据源模板
- 数据源缺乏官网链接, 很难知道参数意思
- 每个参数都需要问号悬浮提示补充 (每个数据源切换后需要有)
- 字段应该分成两类, 一种是用户常用修改的, 一种是虽然必填, 但基本不会变化的
    - 比如字符集/时区/压缩格式这种, 一般都不会修改, 应该放在下面 /分隔开
    - 常用需要修改的重点说明放上面

## /task

所有字段都缺乏问号悬浮提醒, 都应该加上

- `task/edit` 页同样不友好, 而且目标不会选择当前的图空间  + 图数据库, 应该默认加载当前
- 数据源也是应该默认加载第一个 or 上一次选的数据源历史
- 映射的地方也很麻烦, 缺少讲解说明 + 示例



# 系统与运维

## /my

- URL 应该改为合理信息 , 而不是一个 my
- 显示效果应该居中一些, 现在左上角, 显得很丑
    - UI 也可以优化一些, 尽可能做的圆润/美观一些
- 我理解权限应该至少分为 3 种
    - 超级管理员: 拥有所有图空间全部权限
    - 空间管理员: 拥有对应图的管理权限 (可以添加管理人)
    - 普通用户: 对应图的图查询/导入数据权限 (但无法添加)
    - 权限这一块有很多 legacy code 可以去掉不要, 结合 server 最新代码设计, 只需要取**最小可用**即可

## /account 页面

- UI 混乱, 缺乏 问号悬浮注释
- 分配权限设置后报错
- 无法区分普通账号和 admin 权限

## 运维管理

- 首页的运维管理功能主要是什么原因不可用? 文档里记录情况
- 能否提供最小的集群监控/pd/store  情况 (不能/复杂则记录原因先跳过)

# 全局/杂项

## UI/UX

- 当前整体的按钮/文字/边框等还是缺乏美感, 感觉挺生硬, 应该参考设计 Skills 进行合理的优化
- 当前只支持中英文, 就不要使用下拉框, 直接用 CN/EN 点击一键切换即可 ((包括登录界面也是, 无需下拉选择, 一键切换))
- 侧边栏应可折叠, 或者设置自动折叠 (鼠标靠近则固定)
- 尽可能参考设计比较好的 UI/UX 方式进行改进, 独立的 reviewer 线程找不易用不美观的点

## 图可视化引擎

- AntV 系列下的组合版本应该可以进行升级看看是否有效果/功能改进
- 一个个进行测试, 了解核心改进点/收益, 而不是乱升级
- 页面交互上, 尽可能多一些快捷键支持, 包括 "?" 可以显示常用快捷键/全部等
